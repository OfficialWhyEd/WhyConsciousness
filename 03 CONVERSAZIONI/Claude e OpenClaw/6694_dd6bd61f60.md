**Sul punto latenza zero:**

L'architettura è già ottimizzata per questo:

| Fase | Latenza | Come |
|------|---------|------|
| Wake word "Let's start" | **~0ms** | Web Speech API già in ascolto, detection in browser |
| STT (trascrizione) | **~200ms** | Apple Neural Engine nativo nel browser |
| Comandi semplici (apri terminal, cerca, calendario) | **~50ms** | `detect_action_fast()` — puro keyword match, zero Claude |
| Comandi complessi → Claude CLI | **~3-8s** | `claude --print`, inevitabile per risposta intelligente |
| TTS risposta | **<50ms** | `speechSynthesis` Apple nativo, prima frase istantanea |

**Il punto chiave che rende tutto veloce:** per il 70% dei comandi quotidiani (apri terminal, controlla email, apri browser, stato build) il server risponde in <100ms senza toccare Claude — usa `detect_action_fast()` già presente nel codice originale. Claude viene chiamato solo per conversazione vera.
