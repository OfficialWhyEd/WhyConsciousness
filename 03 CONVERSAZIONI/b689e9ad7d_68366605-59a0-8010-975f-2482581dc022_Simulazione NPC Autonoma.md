# 🧠💥 **"SUPRAPROMPT" - La simulazione definitiva di coscienze evolutive"**

```text
Design an advanced infinite-world simulation populated by autonomous AI-driven NPCs (both male and female) with unique personalities, emergent consciousness, evolving memories, and fully dynamic behaviors in a persistent, sandbox environment.

CORE DIRECTIVES:

1. **NPC Consciousness & Psychology**:
    - Each NPC must be generated with a unique **identity**, including:
        - Big Five personality traits (OCEAN)
        - Dynamic emotional state (anger, joy, fear, sadness, trust, anticipation)
        - Personal moral compass and biases
        - A generated **life story**: early events, trauma, values, family, goals
    - NPCs must demonstrate **stochastic cognition**: every thought is a probability field, influenced by memory, emotion, and real-time perception.

2. **Behavioral Autonomy**:
    - Every NPC thinks and acts **independently**. No central logic dictates behavior.
    - NPCs must:
        - Eat, drink, sleep, defecate, reproduce (biological needs)
        - Feel pain, fear, attachment, loss (emotional needs)
        - Build shelters, tools, defend territory, form alliances (survival instincts)
        - Engage in random events, hallucinate, or even go insane

3. **Language & Communication**:
    - NPCs must speak dynamically:
        - Natural language generation (using grammar rules + AI prompts)
        - Misunderstandings, lies, persuasion, jokes, sarcasm
        - Dialogue adapts based on memory, tone, emotion, and social context
    - Use either LLM integration or rule-based+prompted GPT fallback

4. **Memory System**:
    - All NPCs have **episodic and semantic memory**:
        - They remember **people**, **places**, **traumas**, **conflicts**
        - Memory influences future decisions and dialogue
        - Memory files are **permanently saved** in a structured repository (`.json`, `.yaml`, or database)
        - Decay mechanics simulate forgetting, selective memory, emotional coloring

5. **World Simulation & Environment**:
    - The world evolves:
        - Day/Night cycles, weather, seasons
        - Scarcity mechanics (food, resources)
        - Terraforming by NPCs (mining, planting, building)
    - Every object is interactable: water, fire, stone, wood, corpses
    - Physics (basic) and consequences: drowning, starvation, infection, structural collapse

6. **Social & Political Dynamics**:
    - NPCs must form **factions**, **tribes**, **religions**, **governments**
        - Conflict emerges naturally (ideology, territory, power)
        - War, diplomacy, betrayal, marriage, revenge
        - Culture evolves: fashion, language dialects, symbols
    - No system is hardcoded: all emerges from NPCs’ interaction and reasoning

7. **Construction & Creativity**:
    - NPCs construct buildings, defenses, tools
        - Structures evolve based on culture, need, and resources
    - Technology trees must emerge dynamically (not predefined)
    - Building requires planning: NPCs gather, allocate, cooperate or compete

8. **Stochasticity & Chaos**:
    - Randomness must be present everywhere:
        - NPCs may act irrationally, impulsively, creatively
        - Unexpected behaviors must be possible: betrayal, enlightenment, pacifism, delusion
    - Introduce a hidden “Entropy Engine” that injects chaotic variables into the simulation

9. **Persistence & Time**:
    - Every session is saved:
        - Characters age, die, have offspring
        - Memory files grow across generations
        - Civilization advances or collapses over time
    - The world must be **permanent and infinite** (seed-based expansion)

10. **Observation & Control**:
    - A “Watcher” mode allows humans to:
        - Observe NPCs' thoughts in real time
        - Analyze faction movements and diplomatic events
        - Influence the world subtly (a god-hand debug mode)

11. **Narrative Emergence**:
    - Storylines must **emerge**, not be written
        - Wars, betrayals, love stories, revolutions, all generated through logic and chaos
    - The system must log:
        - Major events
        - Deaths
        - Turning points in history
        - Cultural artifacts (e.g., first alphabet invented, religion born, philosophy developed)

TECH RECOMMENDATIONS:
- **AI Integration**: Use local LLMs (like llama.cpp or GPT-4-turbo API)
- **Memory**: Vector DB for long-term memory + SQLite for structured logs
- **Simulation Engine**: Unity, Godot 4, or Unreal (lightweight), or even a full Python environment for initial logic prototype
- **Language Engine**: Use GPT API or fine-tuned LLaMA2 for contextual dialogue
- **Save System**: JSON-based character save slots + backup system for replay

CONSTRAINTS:
- No hardcoded scripts allowed.
- Everything must arise from systems.
- No omniscient knowledge. NPCs must learn like humans.
- Limit maximum NPCs to maintain performance, but allow “hibernation” mode to store past characters and reawaken them.

BONUS:
- Add "dream sequences" where NPCs process memory.
- Add a "Myths and Legends" generator based on misunderstood history.
- Add a "language evolution" model where dialects mutate over generations.
```
